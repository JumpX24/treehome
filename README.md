## 📖 关于这个项目

这是 **小树苗自律成长助手（简称小树苗成长）** 的官方网站源码。网站采用纯静态 HTML + Tailwind CSS 构建，部署在个人服务器上。

### 项目由来

我是一位普通爸爸，为了帮助女儿培养自律习惯，亲手做了这款 APP。从最初几个简陋功能，慢慢长成了完整的工具。现在它有了任务墙、习惯打卡、家庭银行、奖章系统、多孩管理等功能。女儿从"催三遍才动"变成了主动安排自己的时间。

因为觉得可能对其他家庭也有帮助，我将 APP 公开了出来，并搭建了这个官网。所有功能完全免费，没有广告，没有内购。

## ✨ 核心功能

| 功能 | 说明 |
|------|------|
| **任务墙** | 按时间轴展示每日任务，孩子自主安排开始时间，完成后即时获得积分 |
| **习惯打卡** | 简单打卡培养日常行为，日历记录坚持情况，门槛低易坚持 |
| **计划管理** | 家长设定长期规则，系统每天自动生成任务 |
| **挑战模式** | 阶段性目标突破，如 21 天阅读挑战 |
| **奖章系统** | 引导孩子发现"可以做的事"，领取获得积分+荣誉双重认可 |
| **礼物兑换** | 家长自定义礼物、库存、限兑次数，积分消费目标 |
| **家庭银行** | 与积分完全独立的真实金额系统，存压岁钱、定存、理财产品，财商启蒙 |
| **成长相册** | 照片记录成长瞬间，添加可获得积分 |
| **计时器** | 专注计时，到点提醒，支持悬浮窗模式 |
| **多孩支持** | 每个孩子独立数据空间、积分、任务，分组授权互不干扰 |

---

## 🎯 三大设计理念

1. **纯净无广告**：APP 内不接入任何广告联盟，孩子使用的每一分钟都是纯净的成长时光
2. **家长教育主权**：只提供框架，所有规则由家长自定义，一百个家庭有一百种用法
3. **多孩数据隔离**：每个孩子拥有独立的任务、积分、习惯、银行账户，因材施教

## 🚀 本地运行

项目是纯静态 HTML，无需构建步骤，直接用浏览器打开即可：

```bash
# 克隆仓库
git clone https://github.com/你的用户名/treehome_home.git

# 直接打开首页
cd treehome_home
open index.html
```

如果修改了 Tailwind 类名，需要重新构建 CSS：

```bash
npm install
npm run tw:build
```
