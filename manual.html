第一篇 初识APP

第一章 产品简介

小树苗自律成长助手（简称小树苗成长） 是一款专为家庭设计的数字化教育辅助工具，致力于培养孩子的自律习惯，增进亲子互动体验。

本产品支持微信小程序和安卓手机双端运行，家长可通过微信随时管理孩子的学习、生活安排，孩子则可通过独立账号在安卓设备上查看和完成任务。

  • 官网地址：https://www.treehome.top
  • 微信小程序：小树苗自律成长助手
  • 公众号：小树苗自律成长
  • 安卓APP：官网下载

第二章 三大核心理念

2.1 纯净空间，无广告干扰

我们郑重承诺：APP内永不植入任何广告，不接入任何广告联盟。孩子使用的每一分钟，都是纯净、安全、专注的成长时光。

2.2 家长教育主权，数据完全自主

APP只提供框架和能力，所有数据（包括任务、习惯、积分、财务等）均由家长全权掌控和配置，确保教育方式完全符合您的家庭理念。

2.3 多孩数据隔离，因材施教

针对不同年龄段的孩子，APP支持按孩子分组管理。每个孩子拥有独立的任务、积分、习惯、成长记录等数据，互不干扰。大宝可以完成更复杂的挑战，二宝则从基础习惯开始培养——真正实现因材施教。

第三章 快速入门

3.1 获取账号

  • 家长端：通过微信搜索小程序，点击「微信一键登录」即可（首次需绑定手机号）
  • 孩子端：由家长在APP内创建子账号，将账号名和密码告知孩子后登录使用

3.2 添加孩子

登录后进入「我的」页面 → 点击「家长功能」下的「我的孩子」→ 点击右下角「+添加孩子」：

  • 手动添加：填写孩子姓名、性别、出生日期等信息
  • 扫码绑定：另一台设备上已登录的家长可通过扫码方式共享孩子数据（如多位家长共同管理）

3.3 为孩子创建子账号

  1. 进入「我的」→「家长功能」→「孩子账号」
  2. 点击「添加账号」，填写账号名和密码
  3. 选择要关联的孩子（一个账号只能关联一个孩子，关联后该账号登录后只能看到对应孩子的数据）
  4. 将账号名和密码告知孩子，孩子即可在安卓APP端登录

3.4 主界面导航

APP底部设有四个导航标签：

导航说明
首页全局总览，显示积分概览、任务进度、习惯与挑战状态
任务墙按日期查看和管理任务列表
成长屋成长辅助工具（家庭银行、成长相册、计时器等）

第二篇 核心功能体系

第四章 任务、计划、目标——时间管理闭环

本章是APP的核心体系：任务、计划、目标三者相互关联，形成完整的时间管理闭环，帮助孩子建立时间观念、培养自律习惯。

4.1 三者的关系

计划（规则设定） → 自动生成 → 任务（每日执行） → 累计统计 → 目标（周期结算）
功能定位作用执行者
计划长期规则设定孩子应该每天/每周做什么家长配置，系统自动生成任务
任务每日执行具体到某一天需要完成的事项孩子查看并执行
目标周期考核设定一周/一月要完成多少任务系统自动统计并结算

4.2 计划——自动生成每日任务

计划是用于长期、规律性安排的功能，适用于每天都要做的事。

如何创建计划：

  • 设置计划名称（如"每日阅读"、"每天运动30分钟"）
  • 选择循环周期（每天/每周指定星期几）
  • 设置计划起止日期（如"9月1日～1月31日"覆盖整个学期）
  • 设置任务内容和完成后的积分奖励
  • 支持随时暂停、恢复或结束计划

计划如何工作：

  • 后台每天自动根据计划生成当日任务
  • 计划生成的任务没有固定的开始时间
  • 孩子需要在任务墙中自行安排任务的开始时间
  • 设计目的：引导孩子自主进行时间规划，培养时间观念

4.3 任务墙——每日任务执行

任务墙是按时间轴展示任务的核心页面，帮助家长和孩子清晰规划每日安排。

任务来源：

  • 家长或者孩子手动创建的任务
  • 计划自动生成的任务
  • 惊喜任务（特殊隐藏任务，由家长设置后自动随机生成）

任务状态：

状态显示说明
进行中橙色尚未完成，可点击"去完成"
已完成绿色任务完成待家长点评
已超时红色任务超过完成时限
已取消灰色任务被取消

任务操作：

  • 完成任务：孩子点击"去完成"，可上传截图/照片、填写完成说明，完成任务提交后就立即获得任务积分
  • 任务点评（家长）：孩子完成后，家长可以进行评价（赞或踩）、填写意见，点评时可对孩子获得的积分进行浮动
  • 任务延期：将任务延期到后续日期，需填写理由
  • 任务计时：点击沙漏图标启动计时器，支持全屏或悬浮窗模式
  • 修改时间：点击任务左侧时间区域，调整开始时间

4.4 目标——周期性任务考核

目标是对孩子每日任务完成数量的周期性考核，按自然周或自然月进行设置。

如何设置目标：

  • 周目标：设定一个自然周内需要完成的任务总数
  • 月目标：设定一个自然月内需要完成的任务总数
  • 系统按自然周/自然月自动计算截止日期
  • 首页进度条实时显示完成情况

目标结算机制：后台每天自动统计完成情况，截止期限到达时系统自动结算——完成目标获得积分奖励，未达成则自动扣除预设积分（这是整个APP中唯一自动扣分的场景）。

4.5 完整使用示例

家长在学期初设置： 第一步：创建计划 计划名："每日阅读" 循环周期：每天 有效期：9月1日～1月31日 奖励：系统默认计划单次奖励积分为2积分 第二步：计划每天自动生成任务 → 每天0点，系统在孩子任务墙生成一条"每日阅读"任务 → 该任务无固定开始时间，孩子自行安排何时阅读 第三步：孩子执行任务 → 孩子查看任务墙，安排阅读时间 → 阅读完成后点击"去完成"，上传阅读照片 → 家长点评 第四步：设置周目标 目标名："本周目标" 数量：20个任务 周期：本自然周（周一～周日） 完成奖励：50积分，未完成扣分：20积分 第五步：周末自动结算 → 系统统计本周完成25个任务，超出目标 → 孩子获得目标奖励50积分 + 各任务积分 → 播放庆祝动画

第五章 首页——全局总览与快速操作

首页是您每次打开APP后看到的第一个页面，它以孩子为维度展示全局信息。

5.1 顶部孩子信息栏

  • 孩子头像与姓名：显示当前选中的孩子信息，点击头像可查看孩子详细资料
  • 孩子切换：点击孩子姓名右侧的「切换」图标，可在多个孩子之间快速切换
  • 等级标识：显示孩子的当前等级（星星→月亮→太阳→皇冠，逐级提升）
  • 端类型标识：显示当前是「家长端」还是「孩子端」

5.2 概览区域（三张卡片）

卡片内容跳转功能
兑礼物显示当前孩子的可用积分余额点击跳转礼物兑换页

做任务显示今日任务总数，右上角红角标显示未完成数量点击跳转任务墙

5.3 快速添加区

一键创建新功能，快速入口包括：任务、习惯、计划、挑战、照片。

5.4 任务目标进度

显示当前孩子本周/本月的任务目标完成情况，进度条实时更新。

第六章 任务、习惯、奖章、挑战——四大行为引导功能

设计理念：任务、习惯、奖章三者在功能上有一定重叠，但各自侧重点不同，解决不同的教育场景问题。

6.1 三大功能定位对比

功能核心定位时间维度完成方式典型场景
任务每日时间规划当天具体时段设置开始时间，提交详情"下午3点做数学作业"
习惯日常行为养成周期性（每天/指定天数）简单打卡，不限时间"每天喝8杯水"
奖章行为方向引导无时间限制自主完成后领取"跟妈妈分享一件趣事"

6.2 任务——每日时间规划

核心定位：帮助孩子认识时间、规划时间、管理时间。采用时间轴方式进行排版，直观展示一天的任务安排。计划生成的任务没有固定开始时间，需要孩子自己设置开始时间，引导孩子思考"我该什么时候做这件事？"

6.3 习惯——简单打卡培养日常行为

核心定位：以最简单的方式培养孩子的规律性日常行为。通过打卡进行提交，操作比任务更简单，不限制开始时间，打卡记录以日历形式展示，直观看到坚持情况。

6.4 奖章——引导孩子"有事可做"

核心定位：引导孩子知道有什么事可以做，解决"无聊"和"不知道做什么"的问题。奖章列表就像一份"可以做的事"的清单，孩子无聊时可以来看看。侧重于品格培养和社交能力的培养。

典型场景："向爸爸妈妈分享一件趣事"、"完整地表达自己的情绪"、"跟弟弟分享一个玩具"、"帮助家里做一件家务"、"和其他小朋友和好"。

6.5 挑战——阶段性目标突破

挑战用于设定阶段性的、有一定难度的目标，如假期专项训练、学习突破等。家长发起挑战，孩子在截止日期前完成，家长收到通知后进行点评。

第七章 积分与奖章——正向激励机制

积分是整个APP的核心激励机制，贯穿任务、习惯、挑战、奖章等所有环节。APP以正向鼓励和引导为主，不强调扣分和处罚。

7.1 积分的获取

积分来源说明
完成任务完成家长设置的任务，根据设定获得积分
习惯打卡每日坚持习惯打卡，按设定获得积分
完成挑战完成家长发起的挑战，获得额外积分奖励
领取奖章领取家长配置的奖章，获得相应积分
添加成长相册在成长相册中添加照片记录后获得积分
完成目标完成周目标或月目标后获得积分奖励

7.2 等级体系

孩子的积分累计到一定程度会自动升级：星星→月亮→太阳→皇冠。家长可自定义每个等级的名称、所需积分。

7.3 积分的使用

积分可用于兑换家长设置的礼物。进入首页「兑礼物」查看可用积分，选择礼物兑换消耗积分。

7.4 正向鼓励原则

整个APP以正向鼓励和引导为主，唯一自动扣分场景是任务目标未达成时系统自动扣除预设积分，无其他处罚措施。

第八章 奖章系统详解

奖章是行为方向引导工具，代表孩子在某方面的成就和认可。领取奖章可以为孩子增加积分（奖章是加分项，不是消耗积分）。

家长配置奖章：进入「我的」→「奖章管理」→ 创建奖章组 → 添加单个奖章，设置名称、描述、可获得积分、可领取次数上限、授权孩子。

孩子领取奖章：进入首页「领奖章」→ 浏览可领取的奖章卡片 → 点击领取，获得积分。

奖章与礼物的区别

对比项奖章礼物
积分关系领取后获得积分兑换时消耗积分
本质荣誉认可 + 积分奖励积分消费的目标
目的肯定孩子的成就激励孩子努力赚取积分

第九章 礼物系统——积分消费的目标

家长管理礼物：创建礼物分组（如"电子产品"、"玩具"等），设置每个分组对不同孩子的授权，添加单个礼物设置所需积分、兑换次数上限、礼物类型和使用有效期。

孩子兑换礼物：进入首页「兑礼物」→ 浏览礼物列表 → 选择兑换消耗积分 → 在「使用」标签中查看已兑换但未使用的礼物。

第三篇 我的页面与辅助功能

第十章 我的页面——个人信息与功能入口

「我的」页面是个人信息与功能入口页面。顶部提供四个快捷入口：目标、计划、习惯、挑战。

家长功能（仅家长可见）

  • 我的孩子：查看孩子列表、添加孩子、查看详情、编辑信息、生成分享二维码、调整积分、管理等级设置
  • 孩子账号管理：创建/编辑/删除子账号
  • 礼物管理：创建礼物分组和单个礼物
  • 奖章管理：创建奖章组和单个奖章
  • 惊喜任务管理：创建隐藏性质的特殊任务
  • 理财产品管理：添加理财产品用于家庭银行

第十一章 成长屋——成长辅助工具箱

11.1 家庭银行

重要说明：家庭银行是一个完全独立于任务系统的子功能，与积分系统无关。家庭银行使用的是真实金额（元），而非积分。

资产概览：活期余额、定期总额、总资产

操作功能：存入、支取、转定期、购买理财

教育意义：储蓄意识、利息收益、理财启蒙、延迟满足

11.2 成长相册

记录孩子成长过程中的珍贵瞬间：按时间线展示照片，添加照片可获得积分奖励。

11.3 计时器

可独立使用，也可从任务卡片快速启动。支持全屏模式和悬浮窗模式，计时完成时播放提示音。

第十二章 多孩管理与数据隔离

APP中几乎所有功能都以孩子为维度进行数据分组：任务、习惯、计划、挑战、积分与等级、家庭银行、成长相册等均为每个孩子独立计算。

在创建礼物组、奖章组、任务组时，可以设置"授权给哪些孩子"，实现精准施策。通过生成孩子分享二维码，扫码可让多位家长共同管理同一孩子。

第四篇 使用指南与总览

第十三章 家长与孩子端协同使用指南

推荐方案：微信小程序 + 安卓APP 双端协同。家长手机（微信小程序）创建任务、设置奖励；孩子使用安卓APP查看任务、完成任务。

典型使用场景

  • 日常任务管理：家长创建任务 → 孩子查看执行 → 提交完成 → 家长点评
  • 计划自动生成任务：家长创建计划 → 系统自动生成 → 孩子自主安排时间
  • 目标考核与结算：家长设置周目标 → 孩子每日努力 → 系统自动结算
  • 奖章领取与荣誉认可：家长创建奖章 → 孩子达成条件 → 领取获得积分+荣誉
  • 积分消费：家长设置礼物 → 孩子积累积分 → 兑换礼物
  • 家庭银行：家长存入压岁钱 → 孩子转定期 → 到期获得利息

青少年模式兼容性

安卓APP设计为无内嵌浏览器、无社交功能的纯净应用，可安全加入各品牌手机的"青少年模式"白名单。
