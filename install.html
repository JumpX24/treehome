安卓APP安装教程

推荐使用方式：

  • 家长端：通过微信小程序直接登录使用
  • 孩子端：通过安卓APP安装后使用
  • 使用说明：安卓APP安装后需要家长在家长端进行子账号创建并授权后，提供给孩子登录才能够正常使用应用
  • APP优势：安卓APP与微信小程序的功能完全相同，相比于微信小程序具有更好的使用体验，速度更快，计时器更加友好、精准

如需安装使用安卓app。请按照以下步骤操作：

1

下载APK文件

使用手机扫描下方二维码或者直接点击下方下载按钮进行下载

下载APK
2

允许“安装未知来源应用”

下载完成后，点击APK文件开始安装。系统可能会提示“禁止安装未知来源应用”，请按以下步骤操作：

  • 华为/荣耀：设置 → 安全 → 更多安全设置 → 允许安装未知应用 → 找到“浏览器”或“文件管理” → 允许
  • 小米：设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 → 允许浏览器安装
  • OPPO/VIVO：设置 → 安全 → 安装未知应用 → 允许浏览器
  • 三星：设置 → 生物识别和安全性 → 安装未知应用 → 允许浏览器
  • 其他品牌：通常在“设置” → “安全” 或 “隐私” 中找到相关选项
⚠️ 注意：安装完成后，建议关闭此权限以保持手机安全。
3

安装并打开APP

允许安装后，点击“继续安装”或“安装”。安装成功后，在手机桌面找到“小树苗自律成长助手”图标，点击打开。

✅ 首次打开可能会请求通知权限，建议允许，以便接收任务提醒。
4

家长端创建子账号并授权

家长需要在微信小程序中创建账号并登录，然后进入“我的”→“孩子账号”→“添加账号”创建子账号。创建完成后，将子账号提供给孩子，让孩子在安卓APP中使用该账号登录。
